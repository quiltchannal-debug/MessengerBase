# OrangeM — строгая дизайн-система (v2)

Цель редизайна: убрать «пёстрый» вид, все эмодзи и свечения. Интерфейс должен выглядеть
как строгий рабочий инструмент: нейтральные тёмные поверхности, один акцент (оранжевый),
синий — только как дополнительный акцент (ссылки, фокус, выделение), плоские панели,
тонкие границы 1px, аккуратная типографика, минимум скруглений.

## 1. Жёсткие правила

1. **Никаких эмодзи в интерфейсе.** Вместо них — inline-SVG из набора `OM.icon(name, size)`
   (файл `js/ui.js`, ключи в `OM.iconNames`). Допустимые символы: `+ − × ‹ › ← → ↑ ↓ •` и кавычки.
2. **Классы и id не переименовывать.** Вся логика в JS завязана на существующие классы
   (`.post-card`, `.chat-item`, `.msg`, `.panel`, `.switch`, `.toggle`, `.chip`, `.btn`, …).
   Можно добавлять новые классы, но нельзя удалять/переименовывать существующие.
3. **Никаких градиентов** (кроме логотипа/брендовой плашки и заглушки аватара) и
   никаких `box-shadow` с цветным свечением. Тени допускаются только у модалок и меню:
   `0 16px 40px rgba(0,0,0,.5)`.
4. **Плоскость и сетка.** Радиусы: 8px (мелкие), 10px (панели/карточки), 6px (кнопки/поля).
   Отступы кратны 4: 4/8/12/16/20/24. Высота строк списков 44–48px.
5. **Одна акцентная кнопка на экран** (класс `.btn.primary`). Остальные — `.btn.ghost`/`.btn`.
6. **Заголовки разделов** — 15–17px, вес 600; надзаголовки (лейблы групп, поля форм) —
   11px, `text-transform: uppercase`, `letter-spacing:.06em`, цвет `--muted-2`.
7. **Идентификаторы** (Orange ID, uuid, короткий id) — моноширинный шрифт, цвет `--muted`.
8. Движение минимальное: только `background/border/color` переходы 120ms.

## 3. Иконки

`OM.icon('search', 18)` → `<svg class="ico">…</svg>`, рисуется линией 1.6, цвет = `currentColor`.
Доступные ключи (`OM.iconNames`):

```
home chat users stories settings search send attach image video music file heart comment link
trash edit reply react plus close arrow-left arrow-right arrow-up chevron-left chevron-right
chevron-down pin mute eye lock mail phone key qr shield copy check refresh logout user bell chart
globe dots crown star info warning clock camera film tag ban filter verify logout_all download
upload grid megaphone
```

Соответствие старых эмодзи:

| было | стало |
|---|---|
| 🏠 лента | `home` |
| 💬 чаты/комментарии | `chat` / `comment` |
| 👥 сообщества | `users` |
| ⭕ истории | `stories` |
| ⚙️ настройки | `settings` |
| 📎 вложение | `attach` |
| ➤ отправить | `send` |
| ✕ закрыть | `close` |
| ❤️/♥ лайк | `heart` |
| 🔍 поиск | `search` |
| 📌 закреп | `pin` |
| 🔇 без звука | `mute` |
| 👁 просмотры | `eye` |
| 🗑 удалить | `trash` |
| ✏️ изменить | `edit` |
| ↩ ответить | `reply` |
| 😀/➕ реакции | `react` / `plus` |
| 🔗 ссылка | `link` |
| ✉️ почта, 📱 телефон, 🔑 ключ, 🔢 аутентификатор | `mail`, `phone`, `key`, `qr` |
| 🔒 приватность | `lock` |
| ↑ новые публикации | `arrow-up` |
| → ← ↔ навигация | `arrow-right`, `arrow-left`, `chevron-left/right` |

Реакции на сообщения — не эмодзи, а нейтральные символы: `♥ ★ ✓ ? ! ✚` (набор из 6, порядок фиксирован).

## 4. Компоненты (классы уже существуют, менять только вид)

* **Кнопки:** `.btn` — фон `--panel-2`, граница `--line-2`, высота 34px; `.btn.primary` — фон
  `--orange`, чёрный текст `#0c0f13`, без градиента; `.btn.ghost` — прозрачная, граница `--line`;
  `.btn.icon` — квадрат 34×34 с иконкой по центру; `.btn.danger` — красный контур.
* **Чипы/табы:** `.chip` — прозрачный фон, граница, `--muted`; `.chip.active` — фон `--panel-2`,
  текст `--text`, нижняя граница 2px `--orange` (без «пилюли» с заливкой).
* **Поля:** `.input`, `textarea`, `select` — фон `--bg-2`, граница `--line`, фокус — граница `--blue`,
  без внешнего свечения (только `outline:none` + смена границы).
* **Карточки:** `.card`, `.panel`, `.post-card` — фон `--panel`, граница `--line`, радиус 10px.
* **Аватары:** `--panel-2` фон, инициалы 600; «обводка истории» — сплошное кольцо 2px `--orange`
  (непрочитанная) / `--line-2` (прочитанная).
* **Список чатов:** активный элемент — фон `--panel`, левая полоса 2px `--orange`.
* **Сообщения:** свои — фон `--orange-dim`, граница `--orange` 30 %; чужие — `--panel-2`.
  Никаких «пузырей» с хвостами и градиентов.
* **Модалки:** фон `--panel`, граница `--line-2`, радиус 12px, тень тёмная.
* **Бейджи:** `.badge` — серый контур; `.badge.orange` — оранжевый; `.badge.blue` — синий.
* **Сайдбар:** 232px, фон `--bg-2`, граница справа `--line`, пункт меню 40px с иконкой 18px
  и подписью 13.5px, активный — фон `--panel`, левая полоса 2px `--orange`.

## 5. Структура экранов (не менять разметку/ids)

`index.html` содержит все разделы и id; правки допускаются только в оформлении
(замена эмодзи-иконок на SVG, обёртки, классы). Порядок подключения скриптов сохранять.
